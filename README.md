# Days Since War Began

This project is a simple web page that displays the number of days since February 22, 2022. 

It is the day,  when my life stoped. I hate everione who started this war. I remember everithing. And I count days.

---

## Features

- **Dynamic Counter**: Calculates and displays the number of days since the specified date, updated daily.
- **Styling in Ukrainian Flag Colors**: The background is styled in yellow and blue, representing the Ukrainian flag.
- **Responsive Design**: Works well on various devices and screen sizes.

---

## Project Structure

The project consists of the following files:

- `index.html`: The main HTML file containing the structure of the webpage.
- `styles.css`: A CSS file for styling the webpage.
- `script.js`: A JavaScript file to dynamically calculate the number of days.
